各校区宿舍概况

虎溪校区宿舍
大多数新生所在校区

虎溪校区为新校区，宿舍楼较新，设施完善。一般为4人间或6人间，配备独立卫生间、空调、宽带接口。部分楼栋已安装热水器，洗澡方便。

4人间 / 6人间 独卫 空调 宽带接口
A / B 区宿舍
沙坪坝老校区

A/B区为老校区，部分宿舍楼年代较早，条件相对简单，但地理位置好（靠近主城区），距地铁站、商场较近。部分高年级专业在此就读。

4人间 / 8人间 公共浴室 部分无独卫
C 区宿舍
FIC 校区

C区校区宿舍为近年新建，条件较好。部分联合办学项目或特定学院的学生在此居住，宿舍间数少，氛围安静。

4人间 独卫 空调
以录取通知书为准
最终分配由学院决定

具体宿舍楼号和房间号在报到当天领取报到手册后才会确定，部分学院会在新生群提前公布。入住后如有问题可找宿舍管理员或学院辅导员协调。

以通知为准

宿舍常见设施

❄️
空调
大多数宿舍有挂式空调，使用电费从宿舍电费账户扣除，充值在校园卡App操作
🚿
热水 / 洗澡
虎溪部分楼有独立热水器，部分需去集中浴室，需校园卡计费（约0.5–1元/分钟）
🌐
宽带网络
每个床位配一个有线网络接口，月度流量套餐制，超出限速；Wi-Fi覆盖走廊
👕
洗衣
每层或每栋楼设有共享洗衣机（手机App预约 + 支付，约2–3元/次）
🔋
电费充值
宿舍电费独立核算，可在校园卡App或校内充值机充值，余量不足会断电
📦
快递收取
菜鸟驿站 / 快递柜分布在各宿舍楼附近，收到短信/App通知后自取

行李打包清单

需自带（宿舍不提供）
  • 床上四件套（枕套/被套/床单）
  • 枕头、被子（或网购寄到校）
  • 洗漱用品（牙刷、牙膏、洗发水）
  • 毛巾、浴巾
  • 拖鞋（宿舍用 + 公共浴室用）
  • 水杯（保温杯）
  • 台灯（宿舍熄灯后学习用）
  • 充电器、数据线、插线板
  • 网线（部分宿舍需要）
  • 衣架（宿舍晾衣用）
  • 洗衣液/洗衣凝珠
  • 常用药品（感冒药、肠胃药等）
  • 雨伞
  • 存储设备（U盘/移动硬盘）

安全提示：宿舍严禁使用大功率电器（热得快、电磁炉、电热锅等），违规轻则没收重则处分。洗漱间禁止存放充电宝充电过夜。离开宿舍记得关窗、锁门、关闭空调，保管好宿舍钥匙。
